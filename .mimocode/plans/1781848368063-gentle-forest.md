# OCR Trial: 3 страницы бесплатно

## Суть

Дать пользователю 3 страницы OCR бесплатно. Показать чистый результат. Paywall — для апгрейда на Pro, а не для триала.

## Логика

1. OCR обрабатывает первые 3 страницы → показывает чистый результат (editable textarea + download)
2. Под результатом: "N更多的 страниц — с Pro. Все инструменты без лимитов. $3.99/мес" + кнопка Upgrade
3. Trial предлагается через существующий flow (showStudioPaywall / ux-feedback-overlay), а не в OCR результате
