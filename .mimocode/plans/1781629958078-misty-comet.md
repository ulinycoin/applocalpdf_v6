# Plan: Zapier App Integration for LocalPDF

## Overview

Create a Zapier integration that allows users to process PDFs through LocalPDF's API from automation workflows (Google Drive, Dropbox, email, Slack, etc.).

---

## Architecture

```
Zapier Cloud
    ↓ HTTP POST
/api/zapier/process
    ↓ auth check (API key)
    ↓ file processing (WASM on Edge/Node)
    ↓ response
Zapier Cloud
    ↓
Next step (Drive, Email, Slack, etc.)
```

---

## Phase 1: API Foundation (3-5 days)

### 1.1 API Key Management

**New files:**
- `api/keys/create.ts` - Generate API keys
- `api/keys/validate.ts` - Validate API keys
- `api/keys/list.ts` - List user's API keys
- `src/core/api/api-key-manager.ts` - Key generation/validation logic

**Storage:** Vercel KV (Redis) or Postgres

**Key format:** `lp_live_` prefix + 48 random characters

**Rate limits:**
- Free tier: 10 requests/day, 1MB max file
- Pro tier: 1000 requests/day, 50MB max file
- Enterprise: unlimited

### 1.2 Processing API Endpoint

**New file:** `api/process.ts`

```typescript
// POST /api/process
// Headers: x-api-key, Content-Type: application/json
// Body: { file: base64 | url, tool: string, options?: object }
// Response: { file: base64, stats: {...} }
```

**File input support:**
- `file` field accepts either:
  - Base64 encoded string (direct content)
  - HTTP/HTTPS URL (will be downloaded server-side)
- Auto-detection: if starts with `http://` or `https://`, download first

**Supported tools (Phase 1):**
| Tool | Input | Options | Entitlement |
|------|-------|---------|-------------|
| compress-pdf | PDF | quality: number | basic |
| ocr-pdf | PDF | languages: string[] | basic (free) |
| sign-pdf | PDF | signature: base64/url, position: {x,y} | basic |

**Storage:** Vercel KV (free tier: 1GB storage, 100k reads/day, 1k writes/day)

### 1.3 File Processing Adapter

**New file:** `src/core/api/server-processor.ts`

Adapts the existing WASM processing for Node.js/Edge runtime:
- Reuses existing engines (compress-engine, ocr-engine, etc.)
- In-memory VFS (no IndexedDB on server)
- Streaming support for large files

### 2.3 Process PDF Action

**CRITICAL FIX:** Zapier's `type: 'file'` fields provide a URL, not base64 content. The action must download the file first.

```javascript
// zapier/creates/process-pdf.js
const perform = async (z, bundle) => {
  const { file, tool, quality, languages, signature_image, signature_x, signature_y, signature_page } = bundle.inputData;

  // Zapier file fields are URLs - download them first
  const fileResponse = await z.request({
    url: file,
    method: 'GET',
    raw: true,
  });
  const fileBase64 = Buffer.from(fileResponse).toString('base64');

  const options = {};
  if (quality) options.quality = quality;
  if (languages) options.languages = languages.split(',').map(l => l.trim());
  
  // Handle signature image (also a URL from Zapier)
  if (signature_image) {
    const sigResponse = await z.request({
      url: signature_image,
      method: 'GET',
      raw: true,
    });
    options.signatureImage = Buffer.from(sigResponse).toString('base64');
  }
  
  if (signature_x !== undefined && signature_y !== undefined) {
    options.signaturePosition = {
      x: Number(signature_x),
      y: Number(signature_y),
      page: signature_page ? Number(signature_page) : 0,
    };
  }

  const response = await z.request({
    url: 'https://localpdf.online/api/process',
    method: 'POST',
    headers: {
      'x-api-key': bundle.authData.api_key,
      'Content-Type': 'application/json',
    },
    body: {
      file: fileBase64,
      tool,
      options,
    },
  });

  return {
    id: `processed_${Date.now()}`,
    file: response.data.file,
    inputSize: response.data.stats.inputSize,
    outputSize: response.data.stats.outputSize,
    processingTimeMs: response.data.stats.processingTimeMs,
    tool,
  };
};
```

localpdf ocr scan.pdf --lang eng+ja -o searchable.pdf
localpdf sign input.pdf --signature ./sig.png -o signed.pdf

# Batch
localpdf compress *.pdf --output-dir ./compressed/

# Pipe
cat file.pdf | localpdf compress | output.pdf

# Offline (local WASM)
localpdf compress input.pdf --local -o small.pdf
