Описание UI/UX Дизайна LocalPDF V3
Данный документ содержит детальное описание текущего состояния интерфейса и пользовательского опыта (UI/UX) проекта LocalPDF V3. Это описание предназначено для использования в качестве эталона при переходе на новую версию продукта.

1. Философия Дизайна: Liquid Glass
В основе V3 лежит концепция "Liquid Glass" (Жидкое стекло). Это современный стиль, сочетающий в себе элементы глазморфизма (glassmorphism) с динамическими анимациями и эффектами преломления света.

Основные принципы:
Приватность через дизайн: Использование "чистых" и "прозрачных" элементов подчеркивает безопасность и локальную обработку данных.
Глубина и слои: Интенсивное использование размытия заднего плана (backdrop-blur) и теней для создания иерархии.
Премиальность: Акцент на микро-анимациях, градиентах и качественной типографике.
2. Визуальный Язык
Цветовая Палитра
Primary (Основной): Ocean Blue (#3b82f6) — используется для кнопок действия, ссылок и акцентов.
Background (Фон):
Светлая тема: Gray 50 (#f9fafb) с белыми стеклянными карточками.
Темная тема: Privacy Black (#0a0a0a или Zinc 950) — глубокий черный для максимального контраста.
Glass Effects: rgba(255, 255, 255, 0.4) для светлой темы и rgba(28, 28, 30, 0.4) для темной темы с размытием 60px.
Типографика
Inter: Основной шрифт для интерфейса, обеспечивающий читаемость.
Outfit: Используется для логотипа и крупных заголовков, придавая продукту технологичный вид.
Стили: Использование text-balance и text-pretty для красивого отображения длинных заголовков.
Графические Элементы
SVG Liquid Filter: В проекте используется кастомный SVG-фильтр (#liquid-refraction), который создает эффект хроматической аберрации и легкого искажения на "стеклянных" панелях.
Иконки: Сет Lucide-React. Линейные, тонкие иконки (stroke width 2).
3. Структура Интерфейса (Layout)
Header (Шапка)
Высота: 16 (64px).
Фиксированное позиционирование с эффектом размытия.
Слева: Бургер-меню (скрытие сайдбара), Логотип "LocalPDF Sanctuary".
Справа:
Кнопка "Support Developer" (кофейная чашка).
PRO-бейдж или кнопка "Upgrade" (фиолетовый/синий градиент с иконкой молнии).
Кнопка обратной связи (MessageSquare).
Выбор языка (LanguageSelector).
Переключатель темы (Солнце/Луна).
Sidebar (Боковая панель)
Ширина: 64 (256px) в развернутом виде, 16 (64px) в свернутом.
Группировка инструментов по категориям:
Organize (Merge, Split, Remove Pages).
Optimize (Compress).
Convert (PDF to Word, JPG to PDF).
Security (Protect, Sign).
Активное состояние подсвечивается мягким голубым фоном с градиентной границей.
Welcome Screen (Главный экран)
Hero-секция: Крупный заголовок с градиентным суффиксом.
Drop Zone: Огромная область для перетаскивания файлов с закруглением rounded-[3rem].
Анимация при перетаскивании (пульсация, изменение цвета).
Поддерживаемые типы файлов отображаются в виде бейджей.
File Previews: После загрузки файлы отображаются в виде крупных карточек с реальным предпросмотром контента (используется PDF.js для PDF и Canvas для изображений).
4. Пользовательский Опыт (UX)
Поток работы с инструментом:
Загрузка: Пользователь кидает файл в Liquid-зону.
Выбор: Система автоматически предлагает подходящие инструменты на основе типа файла.
Обработка: Появление ProgressBar с текстовым описанием текущего этапа (например, "Analyzing PDF...", "Optimizing images...").
Завершение: SuccessScreen — чистый экран с большой иконкой успеха, кнопкой скачивания и предложениями "Что сделать дальше?" (например, после сжатия предложить защитить паролем).
Ключевые паттерны:
Мгновенный отклик: Использование lazy loading гарантирует быстрый запуск приложения, инструменты подгружаются на лету.
Безопасность прежде всего: Везде присутствуют надписи "Processing is 100% local", "No data leaves your device".
Drag-and-drop везде: Возможность менять порядок файлов в Merge PDF простым перетаскиванием карточек.
5. Технический Стек UI
Framework: React 19 (использование Suspense для всех инструментов).
Styling: Tailwind CSS 3.4.
Components: Radix UI (доступность и логика модалок/селектов).
Toasts: sonner — минималистичные уведомления в углу экрана.
Animations: Утилиты Tailwind + кастомные CSS-анимации (animate-fade-in, animate-slide-up).
6. Адаптивность
Mobile: Сайдбар автоматически сворачивается в иконки. Контейнеры перестраиваются в одну колонку. Зоны клика (touch targets) увеличены до 44px.
Tablet: Сайдбар может быть закреплен или скрыт. Карточки файлов в сетке 2x2.
Desktop: Полноценный Liquid Glass интерфейс с максимальным использованием эффектов.
